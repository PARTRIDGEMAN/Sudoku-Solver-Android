# Sudoku vision fixtures

`real/` contains pinned screenshots from open-source Sudoku projects. See `docs/FIXTURE_SOURCES.md` for source commits, licenses, attribution, and the positive/negative intent of each file.

These assets are test resources only and must not be copied into `src/main` or packaged into release APKs.

Phase 3 should add machine-readable ground truth beside or above this directory. Ground-truth clue matrices and geometry must be manually reviewed from each positive screenshot rather than generated by the detector under test.
